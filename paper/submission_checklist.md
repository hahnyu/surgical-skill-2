# Submission checklist

## Scientific package complete

- [x] Conservative title matches the locked negative/heterogeneous utility result.
- [x] Structured abstract reports participants, interventions, uncertainty, and conclusion.
- [x] Introduction distinguishes protocol gap, identity recovery, model reliance, and intervention utility.
- [x] Related work separates outcome validity, validation protocol, identity permutations, and invariant representation learning.
- [x] Methods describe datasets, inclusion, folds, preprocessing, models, probes, permutations, interventions, tuning, and participant-level inference.
- [x] Results follow the prespecified order: feasibility, protocol gap, identity/formal nulls, verification, utility, controls/robustness.
- [x] Limitations appear before the conclusion and cover all required limitations.
- [x] Every null primary task result includes an interval and the precision/equivalence limitation.
- [x] Dataset-native external scores are described as objective task-performance outcomes, not expert skill ratings.
- [x] Paper 1 overlap is disclosed in the Introduction and Supplement S13.
- [x] Claim-to-evidence matrix restricts causal and clinical language.
- [x] Data/code availability statement reports access restrictions and source licenses.
- [x] Adapted TRIPOD+AI checklist covers all 27 main items and 52 subitems.
- [x] Bibliography contains all manuscript citation keys.
- [x] Phase 6 validator passes.

## Author/editor actions required before journal submission

- [ ] Add final author names, affiliations, ORCIDs, corresponding author, and contribution taxonomy.
- [ ] Add funding and sponsor-role statements.
- [ ] Add competing-interest declarations.
- [ ] Confirm whether the authors’ institution requires an exemption/waiver/determination for this secondary deidentified analysis; insert the exact body and identifier.
- [ ] Confirm source-paper details about assessor blinding where the target was manually scored.
- [ ] Select and add a software license to the repository; update the availability statement accordingly.
- [ ] Select the journal and apply its word count, reference style, figure format, and structured-abstract headings.
- [ ] Add manuscript page and line numbers to the TRIPOD+AI checklist after typesetting.
- [ ] Verify whether the target journal requires a separate AI-use disclosure and write it from the authors’ actual use record.
- [ ] Deposit a release or archival snapshot and replace the repository branch reference with a DOI or permanent release URL if available.
- [ ] Perform final author verification of every table, figure, citation, and source-dataset attribution.

These open items require author or journal information that is absent from the repository. They do not change the locked analysis or manuscript conclusions.
