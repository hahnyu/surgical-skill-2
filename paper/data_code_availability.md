# Data and code availability

Analysis code, environment locks, configurations, aggregate metrics, participant-opaque fold manifests, deterministic figures, source tables, and SHA-256 artifact manifests are available at <https://github.com/hahnyu/surgical-skill-2>. The prospective protocol is preserved at Git tag `protocol-v1`. The Phase 5 locked manifest hash is `a4345fc8cdcb50b90e286914ff6dec8ec1c7373e248f60a260c4eaf11f0d9bc3`.

JIGSAWS is available from its custodians under an academic research agreement: <https://cirl.lcsr.jhu.edu/research/hmm/datasets/jigsaws_release/>. Its raw files, source filenames, participant-level derived records, and trial-level predictions are not redistributed by this repository. Authorized users can place a local copy at the configured path and reproduce the private artifacts; committed manifests disclose their expected row counts and hashes.

The external datasets are available under CC BY 4.0 from their source repositories:

- ROSMA: <https://doi.org/10.5281/zenodo.7100542>
- BGU-SKILLS v1.0: <https://doi.org/10.17617/3.CYSIAP>
- BGU-PatCut v2.1: <https://doi.org/10.17617/3.JK4ANF>

The repository intentionally omits raw data and participant-level prediction files because source terms and privacy constraints differ. Aggregate results needed to verify every manuscript claim are committed. The repository does not currently declare a software license; a license must be selected before describing the code as legally reusable beyond inspection and reproduction by authorized users.
